# Dashboard financiero

## Propósito

Presentar una vista ejecutiva del estado financiero de Sommos.

## KPIs conocidos

- Cash disponible
- CxC pendiente
- CxP pendiente
- Ingresos último mes con datos
- Burn último mes con datos
- Runway
- CxC vencida
- Presupuesto disponible

## Fuente

El Dashboard es una capa de resumen.

No debe tratarse como fuente primaria.

Las cifras deben rastrearse a:

- Bancos
- Transacciones
- CxC
- CxP
- Presupuesto
- Runway Mensual

## Auditoría

Si una cifra del Dashboard parece incorrecta:

1. revisar la fórmula;
2. identificar su fuente;
3. revisar rangos y filtros;
4. comparar con la pestaña origen;
5. revisar estado de pago;
6. revisar fechas;
7. revisar moneda y TC.

Corregir la fuente del problema y no escribir manualmente sobre el KPI derivado.

## Consistencia

Después de una modificación financiera relevante, validar que el Dashboard se actualice sin errores.
